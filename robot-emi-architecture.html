1. 背景與動機

機器人手臂的關節控制訊號,在實際運作環境中會受到多種電磁干擾(EMI)來源影響,包括:

  • 伺服馬達 PWM 驅動產生的高頻雜訊
  • 鄰近變頻器、無線通訊設備的電磁輻射
  • 長距離電纜之間的訊號串擾(crosstalk)

這些干擾若未被妥善處理,可能導致控制訊號中的位元被意外翻轉,使機器人執行「非既定軌跡」的動作,造成安全風險或設備損壞。

本文件推導並記錄一套分層防禦架構,目標是:

  1. 讓系統在訊號遭受隨機位元翻轉時,能夠自動偵測並糾正,不中斷機器人運作
  2. 在無法安全糾正的情況下(多重位元錯誤),系統能誠實回報不確定性,觸發安全機制,而非靜默送出錯誤指令
  3. 在硬體接線層級,從物理上排除危險的矛盾動作(如同一致動器的開/合訊號同時觸發)
重要範疇說明:本架構設計目標是電磁干擾(EMI)——持續性或間歇性、強度相對溫和、通常只影響少數位元的雜訊。本架構不適用於電磁脈衝(EMP)等瞬間高能量、大規模同時破壞甚至造成硬體物理損毀的威脅;EMP 防護需仰賴法拉第籠屏蔽、突波保護器件、光纖隔離傳輸等完全不同層次的工程手段。

2. 第一層:致動層 — 互斥對編碼(Mutual Exclusion Pairing)

2.1 基本規則定義

將控制位元兩兩配對成「互斥對」,每一對之中規定恰好一個位元為 1:

  • 規則1(空間互斥):位元分成 k 組互斥對 (A, A')、(B, B') ……,每組不可同時為 0 或同時為 1
  • 規則2(時間反斥):任兩個合法狀態之間,漢明距離(Hamming distance)必須 ≥ 2

2.2 定理:規則1 自動蘊含規則2

命題:若系統由 k 組互斥對構成,合法狀態共 2k 種,則任兩個不同合法狀態之間的最小漢明距離恆為 2,不須額外驗證。

證明:任取兩個不同的合法狀態,兩者之間必然至少有一整組互斥對的取值不同。由於每組互斥對翻轉時,該對內的兩個位元會同時改變(例如 A=1,A'=0 變成 A=0,A'=1),故每組不同的互斥對貢獻 2 個位元差異。因此最小漢明距離 = 2 × (至少 1 組不同) = 2。∎

2.3 四態範例與循環驅動序列

以 k=2(4 位元、2 組互斥對)為例,合法狀態共 4 種:

狀態AA'BB'
S11010
S21001
S30110
S40101

可排列出一個無限循環、且每步僅翻轉一組互斥對(漢明距離恆為 2)的驅動序列:

S1(1010) → S2(1001) → S4(0101) → S3(0110) → 回到 S1(1010)

此序列與兩相步進馬達的「全步進(full-step)驅動序列」在結構上完全一致,證實此推導與工業界既有實作方法一致。

2.4 致動層的安全價值

互斥對結構的核心價值在於物理層級的安全連鎖(interlock):透過接線本身的拓樸,使「兩個矛盾動作同時觸發」在硬體上成為不可能發生的狀態,不依賴上層軟體邏輯是否正確判斷。即使控制程式發生錯誤或控制晶片當機,此層防護依然有效。

限制:此結構的最小距離為 2,依 Hamming 理論的糾錯公式 ⌊(d-1)/2⌋,距離 2 只能偵測錯誤,無法自動糾正——偵測到異常後只能選擇停機或要求重傳。

3. 第二層:傳輸層 — 漢明碼自動糾錯

3.1 動機

致動層的互斥對編碼僅能偵測錯誤、無法自動糾正,對於長距離、EMI 風險較高的傳輸線路(例如從控制箱到機器人手臂末端的線材),若每次偵測到異常都要求重傳或停機,將造成頻繁中斷,不利於連續運作。因此在傳輸層引入具備自動糾錯能力的漢明碼(Hamming Code)。

3.2 Hamming(7,4) 構造

冗餘位元數推導:設資料位元數 m=4,需檢查位元數 r,須滿足:

2r ≥ m + r + 1

代入 r=3:23=8 ≥ 4+3+1=8,恰好打平,為理論最省的完美碼(perfect code)。

位元配置(位置以二進位表示):

位置二進位角色
1001檢查位 p1
2010檢查位 p2
3011資料位 d1
4100檢查位 p4
5101資料位 d2
6110資料位 d3
7111資料位 d4

編碼規則(偶校驗):

  • p1 = d1 ⊕ d2 ⊕ d4(涵蓋二進位最低位為1的位置:1,3,5,7)
  • p2 = d1 ⊕ d3 ⊕ d4(涵蓋位置:2,3,6,7)
  • p4 = d2 ⊕ d3 ⊕ d4(涵蓋位置:4,5,6,7)

解碼與糾錯:接收端重新計算三組校驗,組成 3 位元「症狀碼(syndrome)」s4s2s1。此症狀碼的二進位值直接對應出錯的位置編號(0 表示無錯誤,1-7 對應上表位置),可直接反轉該位元完成修正,無需重傳。

3.3 距離與能力對照

最小距離 d糾錯能力 ⌊(d-1)/2⌋說明
2(互斥對結構)0僅能偵測,不能糾正
3(Hamming(7,4))1可自動糾正單一位元錯誤

3.4 Hamming(7,4) 的已知弱點

若同時有 2 個位元被干擾翻轉,症狀碼會指向錯誤的位置,系統將誤判為另一個單一位元錯誤,並自信地修正到錯誤方向——這比完全不糾錯更危險,因為系統會靜默送出一個看似合理實則錯誤的指令,且不會發出任何警告。

4. 第三層強化:Extended Hamming(8,4) — SECDED

4.1 動機

為堵住 3.4 節提出的弱點,加入一個總體校驗位元 p0,使系統從「單一錯誤糾正」升級為業界標準的 SECDED(Single Error Correction, Double Error Detection)。

4.2 構造

p0 = p1 ⊕ p2 ⊕ d1 ⊕ p4 ⊕ d2 ⊕ d3 ⊕ d4

即全部 8 個位元(含 p0 自身)的 XOR 結果恆為 0(整體偶校驗)。

距離提升證明:原本 Hamming(7,4) 中任兩個距離恰為 3(奇數)的碼字對,加入全域偶校驗位元後,由於位元翻轉了奇數次,p0 的奇偶性必然也隨之改變,故距離自動提升為 4。

4.3 解碼判斷邏輯

3位元症狀碼整體校驗結果判斷
000通過無錯誤
非000不通過單一位元錯誤,依症狀碼定位並自動修正
000不通過p0 自身被翻轉,其餘7位元正確,僅修正 p0
非000通過雙重位元錯誤——系統識別出無法安全判斷正確值,觸發安全停止/要求重傳,而非靜默送出可能錯誤的指令

此第四種情況正是 Extended Hamming(8,4) 相對於原始 Hamming(7,4) 的核心改進:系統能夠區分「有把握的單一糾正」與「沒把握的雙重錯誤」,在後者情境下選擇保守處理。

    │
    ▼

    ▼
8個位元傳輸 ── (長距離線路,EMI 風險較高) ──▶ 症狀碼 + 總體校驗雙重判斷
                                                  │
                        ┌─────────────────────────┼─────────────────────────┐
                        ▼                         ▼                         ▼
                   0個錯誤:正常放行        1個錯誤:自動糾正,正常放行   2個錯誤:觸發安全停止
                        │                         │
                        └────────────┬────────────┘
                                     ▼
                          還原 4 個邏輯位元
                                     │
                                     ▼
                          互斥對展開 ── (短距離,靠近致動器) ──▶ 8條實體線
                                     │

                       (物理接線保證矛盾動作不可能同時觸發)

5.1 分層設計原則(縱深防禦)

層次面對威脅防禦機制設計理由
傳輸層(長距離)隨機位元翻轉(EMI、雜訊)Extended Hamming(8,4) 自動糾錯+雙重錯誤偵測長線材是雜訊入侵主要入口,需要主動糾正與誠實回報能力
致動層(短距離,靠近硬體)邏輯層級的矛盾指令互斥對物理接線物理上直接排除危險狀態,不依賴軟體正確性的獨立保底防線

兩層機制性質不同、互相獨立,即使其中一層失效(例如解碼器本身故障),另一層依然能提供保護,符合工業安全設計中的縱深防禦(defense in depth)精神。

6. 效益與限制的誠實評估

6.1 實際會強化的部分

  1. 訊號完整性:單一位元錯誤的容忍率從 0% 提升到 100%(可自動糾正)
  2. 降低非計畫性停機:單一位元錯誤不再需要中斷或重傳
  3. 物理層級的危險動作防護:矛盾致動指令在硬體接線層級即被排除,不依賴軟體邏輯

6.2 不會被強化的部分

  1. 不提升機器人的決策能力或「智慧」:本架構解決的是訊號完整性問題,與感知、規劃、決策等自主智慧層次的問題無關
  2. 不能抵禦 EMP 或系統性硬體損壞:架構假設為隨機、獨立的位元翻轉,面對同時大規模破壞或硬體物理燒毀的情境無效
  3. 雙重以上錯誤仍有殘餘風險:SECDED 保證雙重錯誤「至少不會被誤判成單一錯誤而靜默犯錯」,但仍無法自動糾正;三重以上錯誤的行為未在本文件範圍內驗證

6.3 成本考量

Extended Hamming(8,4) 相較於原始 4 位元傳輸,需多 4 條線路與對應編解碼電路;互斥對展開後致動端需 8 條實體線。是否值得投入,應視實際部署環境的 EMI 強度而定——高干擾工業環境(電焊機器人、電力設備旁)效益明確,低干擾環境(一般室內協作機器人)可能構成過度工程。
